Explicit FTCSO(Δt + Δx²)

Tᵢˡ⁺¹ = λTᵢ₋₁ˡ + (1−2λ)Tᵢˡ + λTᵢ₊₁ˡ

Conditionally stable: requires λ ≤ 0.5. Direct march forward; oscillates & diverges if λ > 0.5.

Simple Implicit BTCSO(Δt + Δx²)

−λTᵢ₋₁ˡ⁺¹ + (1+2λ)Tᵢˡ⁺¹ − λTᵢ₊₁ˡ⁺¹ = Tᵢˡ

Unconditionally stable for all λ > 0. Solves a tridiagonal system via O(N) Thomas algorithm each step.

Crank–NicolsonO(Δt² + Δx²)

−λTᵢ₋₁ˡ⁺¹ + 2(1+λ)Tᵢˡ⁺¹ − λTᵢ₊₁ˡ⁺¹ = RHSˡ

Unconditionally stable and 2nd-order accurate in both space & time by averaging levels l and l+1.
